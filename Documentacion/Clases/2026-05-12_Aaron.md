## Contexto

PRACTICO 8: Taxi Mobile: Sistema web mobile para seguimiento de taxis

**Sistema:** Taxi Mobile es una aplicación web mobile para seguimiento de taxis desde una central.

**Dominio:**

- Los **pasajeros** usan una app mobile para solicitar el taxi más cercano y ver su ubicación y demora.
- Los **taxistas** también usan una app mobile que usa el sistema de posicionamiento del celular para informar su ubicación. Deben estar registrados en una central que haya contratado el servicio.
- La **central** usa una aplicación web (no mobile) para ver el estado de todos los taxis en un mapa.

**Estados de un taxi y su color en el mapa de la central:**

- 🟢 Verde: Libre
- 🟡 Amarillo: Solicitado
- 🔴 Rojo: Ocupado
- ⚫ Negro: Fuera de servicio

**Filtros disponibles en la central:** por Barrio, por Estado, por chapa del taxi.

**Información visible al pasar el mouse sobre un taxi:**

- Taxi **ocupado**: datos del pasajero (nombre, apellido, celular), hora de inicio y costo del viaje.
- Taxi **solicitado**: solo datos del pasajero.

### US – Ver mapa de taxis

**Tarjeta canónica:**

> **Como** Administrador de la Central,
> **quiero** ver la ubicación de todos los taxis de la central y si tienen viajes en curso,
> **para** saber la disponibilidad actual.

**Estimación:**

| Complejidad       | Esfuerzo          | Incertidumbre     |
| ----------------- | ----------------- | ----------------- |
| (baja/media/alta) | (baja/media/alta) | (baja/media/alta) |

| Método       | Valor | Fundamento |
| ------------ | ----- | ---------- |
| Fibonacci    |       |            |
| Talla remera |       |            |

**Criterios de aceptación:**

- Debe mostrar taxis en todos los estados (Verde: Libre, Amarillo: Solicitado, Rojo: Ocupado, Negro: Fuera de Servicio).
- Solo se muestran taxis que tienen habilitado el sistema de ubicación.
- Pasando el mouse sobre un taxi ocupado, debe mostrar: datos del pasajero (nombre, apellido, celular), hora de inicio y costo del viaje.
- Si el taxi está solicitado, solo se visualizarán los datos del pasajero.
- Puede filtrar por Barrio, por Estado y por chapa del taxi.

**CE:** 1, 6, 8, 9, 11, 15, 18, 25

## Conceptos clave

| Término                          | Descripción breve                                                                                     |
| -------------------------------- | ----------------------------------------------------------------------------------------------------- |
| Clase de Equivalencia (CE)       | Agrupación de entradas/salidas que el sistema trata de la misma manera; probar uno representa a todos |
| CEV (Clase Equivalente Válida)   | Entrada dentro del rango esperado y aceptado por el sistema                                           |
| CEI (Clase Equivalente Inválida) | Entrada fuera del rango esperado; debe producir un error o rechazo                                    |
| Casos de Prueba                  | Combinación mínima de CEs que cubre todos los escenarios identificados                                |
| Caja Negra                       | Técnica de testing que prueba funcionalidad sin conocer la implementación interna                     |
